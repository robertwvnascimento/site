ComandaBox — Visão Geral do Produto
PDV offline para festas, quermesses e eventos sazonais. Sem internet, sem mensalidade, sem driver.
STICK
ComandaBox Stick
Conecta via cabo Ethernet em qualquer impressora de rede. Gera Wi-Fi AP para o operador acessar o PDV pelo celular ou tablet. 1 unidade = 1 caixa = 1 impressora.
  • ESP32-ETH01 (Wi-Fi + Ethernet)
  • Alimentação USB-C 5V
  • Funciona com qualquer impressora com porta de rede (TCP 9100)
  • Servidor web embarcado no LittleFS
  • Dimensões: ~65 × 40 × 18 mm
  • Custo de produção: R$ 35–55

Wi-Fi — Identificação, senha e factory reset
Nome da rede (SSID)
COMANDABOX-A4F2
Gerado automaticamente na inicialização a partir dos 4 últimos dígitos do endereço MAC do módulo. Cada aparelho tem um SSID único. Não é possível alterar o SSID — só é diferente porque o MAC é diferente.
C: snprintf(ssid, 24, "COMANDABOX-%02X%02X", mac[4], mac[5]);
Senha padrão de fábrica
COMANDABOX
Alterável no painel Admin (requer senha atual). A nova senha é salva na NVS do ESP32 e sobrevive a reinicializações.

Perdeu a senha? Necessário factory reset físico para restaurar.
Factory Reset (GPIO32 — botão físico)
1. Desligue o aparelho
2. Pressione e segure o botão RESET
3. Ligue o aparelho
4. Solte após 5 segundos (LED pisca 3×)

Apaga: senha Wi-Fi, produtos, pedidos e configurações.
Mantém: firmware (não precisa regravação).
Modelo de comanda
Cada item do pedido gera uma ficha individual (ex: 2x Cachorro Quente). Ao final, um comprovante total. O cliente entrega a ficha correta em cada balcão.

Por quê? Facilita organização em eventos com múltiplos pontos de retirada (lanches, bebidas, doces).
Senha do dia
Uma palavra ou código definido no painel admin antes de abrir o caixa. Impressa em destaque em toda ficha.

Objetivo: Invalidar fichas de dias anteriores automaticamente. Se a senha de hoje é FOGUEIRA, não adianta apresentar ficha de ontem com MILHO.
Dashboard e relatórios
Todos os pedidos são salvos no dispositivo. O painel admin exibe:

Fichas de Impressão — Formato e Especificação
Sistema gera 1 ficha por unidade (vai ao cliente) + 1 comprovante (fica com o operador/cozinha). Corte automático após o comprovante.
🟢 Fichas de item → cliente. Uma ficha por unidade. O cliente apresenta nos balcões para retirar cada item.
🟡 Comprovante → operador. Último a imprimir, corte automático. Vai para a fila da cozinha. Operador chama pelo número quando pronto.

Configuracao de rede — SSID dinamico
// Gera SSID na inicializacao a partir do MAC uint8_t mac[6]; esp_efuse_mac_get_default(mac); char apSSID[24]; snprintf(apSSID, 24, "COMANDABOX-%02X%02X", mac[4], mac[5]); // Ex: "COMANDABOX-A4F2" // Senha salva na NVS (padrao COMANDABOX) String apPass = nvs.getString( "ap_pass", "COMANDABOX"); WiFi.softAP(apSSID, apPass.c_str()); IP AP: 192.168.4.1 Reset: GPIO32 segurado 5s no boot // Ethernet (LAN8720) — simultaneo GPIO MDC: 23 MDIO: 18 GPIO CLK: 0 PWR: 16 // Impressora TCP Porta: 9100 IP: configuravel
Analise de memoria — ESP32-ETH01 (4MB Flash / 520KB SRAM)
Flash 4MB — Particionamento recomendado
# partitions.csv (sem OTA) nvs 0x9000 0x6000 = 24KB (NVS/WiFi pass) phy_init 0xF000 0x1000 = 4KB (ETH LAN8720) factory 0x10000 0x280000 = 2.5MB (firmware) spiffs 0x290000 0x170000 = 1.4MB (LittleFS)
Sem OTA = mais espaco LittleFS. OTA pode ser adicionado via endpoint /api/update com particionamento 2×1.5MB.

Restricoes criticas para o firmware
⚠ Chart.js CDN (600KB+) nao pode ser usado. Substitua por graficos SVG customizados (~12KB) ou tabelas simples no firmware.
⚠ Google Fonts requer internet. Use system fonts no firmware: -apple-system, sans-serif.
✓ ESP32-ETH01 nao tem PSRAM, mas os 141KB RAM livres sao suficientes para servir paginas gzipadas e processar JSON.
✓ ESPAsyncWebServer serve .gz nativamente — basta nomear o arquivo como index.html.gz e ele envia o Content-Encoding correto.
Factory Reset — implementacao no firmware
// main.cpp — setup() const int RESET_PIN = 32; // GPIO32 livre no ETH01 pinMode(RESET_PIN, INPUT_PULLUP); // Detecta botao pressionado no boot if (digitalRead(RESET_PIN) == LOW) { unsigned long t = millis(); while (digitalRead(RESET_PIN) == LOW) { if (millis() - t > 5000) { // 5 segundos: executa reset doFactoryReset(); break; } // Pisca LED de aviso (GPIO2) digitalWrite(2, !digitalRead(2)); delay(300); } } void doFactoryReset() { nvs.clear(); // apaga senha Wi-Fi LittleFS.remove("/settings.json"); LittleFS.remove("/products.json"); LittleFS.remove("/orders.json"); // Pisca 3x (confirmacao visual) for (int i=0; i<3; i++) { digitalWrite(2, HIGH); delay(200); digitalWrite(2, LOW); delay(200); } ESP.restart(); }
GPIO32 e GPIO33 sao os unicos GPIOs de proposito geral com pullup interno disponiveis no ESP32-ETH01. GPIO0 (ETH CLK) e GPIO16 (PHY PWR) nao podem ser usados como botao.
