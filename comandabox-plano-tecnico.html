Fluxo de uso — identico nas tres versoes
1
Configurar
Define produtos, senha do dia e nome do evento no painel admin.
2
Lancar pedido
Operador acessa a interface pelo celular, seleciona itens e confirma.
3
Imprimir fichas
1 ficha por unidade (vai ao cliente) + 1 comprovante (fica no caixa/cozinha).
4
Chamar no painel
Quando pronto, operador chama o numero no painel eletronico. Cliente retira.

✓ Orcamento limitado

ESC/POS — sequencia de bytes para impressao
// printer.cpp — printItemFicha() ESC @ (init printer) 1B 40 ESC t 02 (charset CP850) 1B 74 02 ← PT-BR acentos ESC a 01 (centralizar) 1B 61 01 ESC E 01 (bold on) 1B 45 01 GS ! 11 (2x width+height) 1D 21 11 ← COMANDA #NNN [texto numero da comanda] GS ! 00 (normal) 1D 21 00 [texto senha do dia] GS ! 10 (2x height) 1D 21 10 ← nome do item ESC E 00 (bold off) 1B 45 00 GS ! 00 (normal) 1D 21 00 [preco unitario] ESC a 00 (esquerda) 1B 61 00 [rodape: PDV-ID + RETIRE NO BALCAO] GS V 42 00 (corte parcial) 1D 56 42 00 ← so no comprovante
✎ Corte automatico (GS V) so e enviado apos o comprovante (ultimo a imprimir). As fichas de item NAO cortam — impressora libera papel suficiente entre elas via feed de linha.

Rede do evento
A impressora 58mm com interface TTL opera a 5V logico. O ESP32-ETH01 tambem e 5V tolerant nos pinos UART. Conexao direta sem nivel logico adicional.
A fonte 5V/3A suporta ambos: ESP32 (~280mA pico) + impressora (~2A no cutter + cabeca termica). Total maximo: ~2.3A, margem de seguranca com 3A.
O firmware detecta o modo de impressao via #define PRINTER_MODE_SERIAL em config.h. A mesma base de codigo compila para Stick e Pro.
ComandaBox Server — Raspberry Pi 3 Model B
Servidor Linux completo. Multiplos operadores, multiplas impressoras, banco de dados relacional, WebSocket em tempo real. Para eventos medios, grandes ou instalacoes fixas.
Conceito chave: O Raspberry Pi e ao mesmo tempo o servidor da aplicacao web E o hub de impressao. Operadores acessam via Wi-Fi/Ethernet pelo navegador. Cada operador tem uma impressora atribuida. O sistema pode ainda dividir o pedido por categoria: fichas de lanches vao para a impressora da cozinha, fichas de bebidas para o bar, comprovante fica no caixa.

Roteamento de impressao — feature exclusiva do Server
O sistema usa uma hierarquia de 3 niveis para decidir qual impressora recebe cada ficha:
Nivel 1 — Produto especifico
Se um produto tem impressora propria definida, usa ela. Ex: "Cerva gelada" sempre vai para o bar.
Nivel 2 — Categoria
Se a categoria tem impressora definida. Ex: "Lanches" → Cozinha, "Bebidas" → Bar.
Nivel 3 — Impressora do operador
Fallback: impressora atribuida ao operador que fez o pedido.
O comprovante total sempre vai para a impressora do operador (caixa), independente do roteamento das fichas.

CUPS para USB. TCP:9100 raw para impressoras de rede. ESC/POS customizado.

Wi-Fi AP no RPi. SSID configurable. IP fixo 192.168.4.1. DHCP local.

Configuracao de rede — dois modos
Modo A — RPi como ponto de acesso (Wi-Fi AP)
# /etc/hostapd/hostapd.conf interface=wlan0 ssid=COMANDABOX hw_mode=g channel=6 wpa=2 wpa_passphrase=COMANDABOX wpa_key_mgmt=WPA-PSK # /etc/dnsmasq.conf interface=wlan0 dhcp-range=192.168.4.100,192.168.4.200,24h address=/comandabox.local/192.168.4.1
Modo B — RPi na rede existente (Ethernet)
# /etc/dhcpcd.conf interface eth0 static ip_address=192.168.1.10/24 static routers=192.168.1.1 # Operadores acessam: http://192.168.1.10 ou http://comandabox.local (mDNS)

Escalabilidade e upgrades
→ RPi 4 (upgrade)
Mesmo software, apenas troca o hardware. RPi 4 tem Gigabit Ethernet real, USB 3.0 e 4-8GB RAM — 10x mais rapido para eventos muito grandes.
→ PostgreSQL (banco externo)
Para eventos recorrentes ou historico multi-evento, substituir SQLite por PostgreSQL no proprio RPi ou servidor remoto.
→ Display local (LCD/touchscreen)
RPi 7" touchscreen no GPIO — pode ser o proprio painel de senhas fisico ou monitor de administracao local.
→ Multi-RPi (clusters)
Para festas muito grandes: um RPi por setor, sincronizados via Ethernet com banco compartilhado.

Arvore de decisao — qual versao escolher?
Tenho so 1 caixa e ja tenho impressora de rede?
→ ComandaBox Stick (mais barato, facil)
Tenho so 1 caixa e nao tenho impressora de rede?
→ ComandaBox Pro (plug & play, tudo incluso)
Varios caixas OU varios balcoes de retirada?
→ ComandaBox Server (RPi) — unica opcao
Evento recorrente/fixo ou lanchonete permanente?
→ ComandaBox Server — banco de dados, historico, relatorios avancados
Quero escalar depois?
→ Compre varios Stick/Pro para eventos pequenos, e Server para os grandes. Nao sao excludentes.
